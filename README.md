# OMNISCENT — Luxury Perfume E-Commerce

A multi-page luxury fragrance e-commerce website built with **pure HTML, CSS, and vanilla JavaScript** — no frameworks, no dependencies.

## Pages Included

| Page | File | Description |
|------|------|-------------|
| **Page 6** | `page6-signature-floral.*` | Product Detail — Signature Floral EDP (Women's). Scent notes pyramid, gallery tabs, size selector, reviews, cart. |
| **Page 7** | `page7-woody-amber.*` | Product Detail — Woody Amber Extrait (Unisex). Live bottle monogram engraving, accord meters, olfactory layer tabs, accordion. |
| **Page 8** | `page8-fragrance-quiz.*` | Fragrance Quiz / Scents Finder. 5-question interactive quiz with weighted scoring engine, personalized scent DNA result, dynamic SVG bottle art. |

## Theme

Matches the **OMNISCENT** brand identity:
- **Palette:** Obsidian black · Blush cream (`#FBF4EF`) · Rose accent (`#CC6E68`) · Rose-gold metallic
- **Typography:** Playfair Display (serif headings + italic accents) + Plus Jakarta Sans (body)
- **Layout:** Arch-shaped product showcases · 4-column product grids · Sticky header with live cart drawer

## Features

- ✅ Shared `localStorage` shopping cart across all 3 pages
- ✅ Slide-over cart drawer with remove items & subtotal
- ✅ Live search drawer with autocomplete chips
- ✅ Responsive layout (mobile breakpoints at 960px & 560px)
- ✅ Fully accessible (ARIA labels, roles, live regions)
- ✅ No external dependencies — open any `.html` file directly in a browser

## Usage

```bash
# Clone
git clone https://github.com/i263031/OMNISCENT.git
cd OMNISCENT

# Open any page directly
start page6-signature-floral.html   # Windows
open page6-signature-floral.html    # macOS
```
